# Cutroom V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native) unless the user picks subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local-first desktop spike: session EDL in TypeScript, WAV peaks/play/export in Rust, Tauri shell that can import one file, cut a range, and write a mixdown — plus a written path for transcript delete and review later.

**Architecture:** Shared `@cutroom/session-model` owns the EDL. `crates/audio-engine` decodes, builds peak mipmaps, plays, and renders. `apps/desktop` is Tauri 2 + React. Cloud review and Expo are out of this plan.

**Tech Stack:** pnpm workspaces, TypeScript, Vitest, Zod, nanoid, Rust 2021, hound, rodio/cpal, serde, Tauri 2, React, Vite.

**Spec:** [docs/specs/2026-10-12-session-model.md](../../specs/2026-10-12-session-model.md)

## Global Constraints

- Node 20+, pnpm 10.28.2, Rust 1.98, ffmpeg available on PATH for later MP3, not required for WAV spike.
- Field names camelCase in JSON (`sourceInSec`, `timelineStartSec`).
- Original media is never overwritten; export writes a new path.
- Max 4 tracks. Sample rate locked to first ingested file.
- Loudness target −16 LUFS / −1 dBTP is a constant in session-model; engine apply comes after WAV export works.
- No VST, video, cloud stem upload, or mobile cutter in this plan.

## Review Focus

- Split-clip range delete: a clip that fully contains `[t0, t1)` must become two clips, right piece starting at `t0` after ripple.
- Word visibility: words whose source time is no longer covered by any clip must disappear from `visibleWords`.
- Linked ripple: deleting 2s on track A must also close 2s on track B at the same timeline range.
- Sample-rate mismatch: ingest of a second file with a different rate must fail, not resample silently.
- Fade bounds: `fadeInSec + fadeOutSec` must not exceed clip duration; clamp, do not panic.

### Task 4: Transcript words follow clips

**Files:**
- Create: `packages/session-model/src/transcript.ts`, `packages/session-model/src/transcript.test.ts`

**Interfaces:**
- Consumes: `Project`, `sourceToTimeline`, `removeLinkedRange`
- Produces:

```ts
export function visibleWords(project: Project): Word[];
export function deleteWords(project: Project, wordIds: string[]): Project;
```

`visibleWords`: keep words where some clip on `word.trackId` covers `word.sourceStartSec`.  
`deleteWords`: compute min/max **timeline** times of those words (using the covering clip), then `removeLinkedRange`.

### Task 5: Rust audio engine — peaks and WAV render

**Files:**
- Create: `crates/audio-engine/src/lib.rs`, `crates/audio-engine/src/peaks.rs`, `crates/audio-engine/src/render.rs`, `crates/audio-engine/src/session.rs`, `crates/audio-engine/Cargo.toml`

**Interfaces:**
- Consumes: JSON `Project` matching session-model camelCase
- Produces:

```rust
pub fn write_test_sine(path: &Path, secs: f32, sr: u32) -> Result<(), EngineError>;
pub fn peaks_minmax(pcm: &[f32], bucket: usize) -> Vec<(f32, f32)>;
pub fn render_wav(project: &Project, dest: &Path) -> Result<(), EngineError>;
```

`render_wav` mixes clips onto a mono or stereo buffer at `project.sample_rate`, applying linear fades and `gainDb`, then writes PCM16 WAV with `hound`. Dual-track: sum, clip to [-1, 1].
